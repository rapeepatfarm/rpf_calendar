# เปิดให้ดูจากนอกฟาร์มด้วย Tailscale

## ทำไมต้อง Tailscale

โปรแกรมนี้เก็บข้อมูลไว้ในฐานข้อมูลบนเครื่องที่ฟาร์ม และคนที่ต้องใช้คือคนในบริษัท
ไม่กี่คน จึงไม่คุ้มที่จะย้ายขึ้นคลาวด์และเปิดออกสู่อินเทอร์เน็ตสาธารณะ
ทางเลือกคือ "จะเปิดให้เข้าถึงอย่างไรให้ปลอดภัย" มากกว่า "จะย้ายไปไหน"

ใช้วิธีเดียวกับ RPF Power เพื่อให้ดูแลชุดเดียว — เครื่องที่ลง Tailscale แล้ว
เข้าได้ทั้งสองโปรแกรม ต่างกันแค่หมายเลขพอร์ต (RPF Power 8100 · RPF Calendar 8200)

Tailscale สร้างเครือข่ายส่วนตัวเข้ารหัส (WireGuard) ระหว่างเครื่องที่ลงแอปไว้ด้วยกัน
**ไม่มีอะไรเปิดออกสู่อินเทอร์เน็ตเลย** ไม่ต้องเปิด port ที่เราเตอร์ ไม่ต้องมี IP จริง
ไม่ต้องมีชื่อโดเมน และใช้ได้แม้ผู้ให้บริการเน็ตจะใช้ CGNAT

ข้อแลกเปลี่ยนคือทุกเครื่องที่จะดูต้องติดตั้งแอป Tailscale และล็อกอินก่อน
เหมาะเมื่อคนดูเป็นคนในบริษัทจำนวนไม่มาก

## ขั้นตอนติดตั้ง

### 1. เครื่องเซิร์ฟเวอร์ที่ฟาร์ม

ดาวน์โหลดจาก <https://tailscale.com/download/windows> ติดตั้งแล้วล็อกอิน
(สมัครฟรีด้วยบัญชี Google ได้ แผนฟรีรองรับ 100 เครื่อง)

ตั้งให้เริ่มทำงานพร้อม Windows เพื่อไม่ต้องเปิดเองทุกครั้งที่ไฟดับแล้วเครื่องรีสตาร์ท

จดเลข IP ที่ Tailscale ให้ — จะขึ้นต้นด้วย `100.` เช่น `100.101.102.103`
ดูได้จากไอคอนใน system tray หรือสั่ง:

```
tailscale ip -4
```

### 2. เครื่องหรือมือถือที่จะใช้ดู

ติดตั้งแอป Tailscale (มีทั้ง iOS, Android, Windows, macOS) แล้วล็อกอิน**ด้วยบัญชีเดียวกัน**
กับที่ใช้ในข้อ 1 เท่านั้น เครื่องจะเห็นกันเองอัตโนมัติ

เปิดเบราว์เซอร์ไปที่ `http://100.101.102.103:8200` (แทนด้วยเลขจริงจากข้อ 1)

### 3. ตั้งค่าโปรแกรม

แก้ไฟล์ `.env` เพิ่มบรรทัดนี้ แล้วรีสตาร์ทโปรแกรม:

```
ONLINE=1
```

ผลที่ได้: อายุการล็อกอินสั้นลงเหลือ 12 ชั่วโมง (จากเดิม 14 วัน) และโปรแกรมจะไม่ยอมเริ่ม
ถ้า `SESSION_SECRET` ยังเป็นค่าเริ่มต้น

**อย่าเพิ่งตั้ง `SESSION_HTTPS_ONLY=1`** ถ้าเข้าผ่าน `http://100.x.x.x:8200` ธรรมดา
เพราะจะล็อกอินไม่ได้ — Tailscale เข้ารหัสให้อยู่แล้วในระดับเครือข่าย

### 4. (ถ้าต้องการ HTTPS จริง) เปิด Tailscale Serve

จะได้ชื่อที่จำง่ายและมีกุญแจล็อกในเบราว์เซอร์:

```
tailscale serve --bg 8200
```

จะได้ URL แบบ `https://ชื่อเครื่อง.ชื่อtailnet.ts.net` ใช้แทนเลข IP ได้
เมื่อใช้แบบนี้ให้เพิ่ม `SESSION_HTTPS_ONLY=1` ใน `.env` ด้วย

## บัญชีสำหรับคนที่ดูจากภายนอก

ใช้สิทธิ์ **worker** สำหรับคนที่ต้องกดเริ่ม/สิ้นสุดงานของตัวเองจากมือถือ
หรือ **viewer** สำหรับคนที่ดูอย่างเดียว
เมนูตั้งค่าจะถูกซ่อน และถึงจะพิมพ์ URL ตรงๆ ก็ถูกปฏิเสธ

สร้างบัญชีใหม่ได้จากหน้า **ผู้ใช้งาน** หรือสั่งจากเครื่องเซิร์ฟเวอร์:

```
python D:\RPF_Systems\rpf_calendar\scripts\create_user.py --username somchai --role worker --display-name "สมชาย"
```

## สิ่งที่ต้องระวัง

- **เครื่องที่ฟาร์มต้องเปิดตลอด** ถ้าปิดหรือเน็ตหลุด จะดูจากภายนอกไม่ได้และข้อมูลจะขาดช่วงด้วย
- **ให้ทุกคนเปลี่ยนรหัสผ่านของตัวเอง** ที่หน้าบัญชีของฉัน หลังได้รับรหัสครั้งแรก
- **อย่าใช้ Tailscale บัญชีเดียวกับคนนอกบริษัท** เพราะทุกเครื่องในบัญชีเดียวกันเห็นกันหมด
  ถ้าต้องแยกสิทธิ์ให้ใช้ฟีเจอร์ ACL ของ Tailscale
- ถ้าเปลี่ยนใจไปใช้วิธีเปิด port ที่เราเตอร์แทน **อย่าทำ** โปรแกรมนี้ยังไม่ได้ออกแบบมาให้
  รับการยิงจากอินเทอร์เน็ตโดยตรง (ไม่มี TLS ในตัว ไม่มี WAF)
